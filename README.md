# Неделя для неё ♥

Статичный сайт без сборки: `index.html`, `css/`, `js/`. Открывается на GitHub Pages, Vercel или любом хостинге.

## Настроить под себя
Всё в **`js/config.js`**: обращения (без имени), подпись, дата старта (`startDate` — день 1, далее по дню в сутки), письма на каждый день, причины, картинки для мемори (эмодзи или `photos/1.jpg`), фраза из шариков, желания для фонариков, финальный вопрос.

## Проверить
- `?preview` — открыть все дни сразу (например `http://localhost:5178/?preview`)
- `?reset` — сбросить прогресс
- Локально: `python3 -m http.server 5178`, затем с другого устройства в сети: `http://<IP-мака>:5178`

## Дни
1. Поймай сердечки (canvas-игра) · 2. Скретч-карты с причинами (стирать долго) · 3. Мемори · 4. Созвездие-сердце (тянуть линию) · 5. Шарики со словами · 6. Фонарики желаний · 7. Вопрос с убегающей кнопкой «Нет» → салют

После каждой игры — конверт с письмом (печатается вживую). Прогресс хранится в браузере.

## Деплой
**GitHub Pages:** залить в репозиторий → Settings → Pages → Deploy from branch → `main` / root.
**Vercel:** `npx vercel` в папке (framework: Other, без build-команды).
